# Красота с любовью — бьюти-пространство в Гатчине

Статический сайт, собранный по референсу клиента. Без сборки и зависимостей —
открывается как есть, кладётся на любой хостинг / GitHub Pages.

## Структура

```
index.html        Главная: хиро, «Наше пространство», «Направления»,
                  Обучение (#obuchenie), Мастер-классы (#masterclasses),
                  О нас (#about), CTA-полоса, подвал
coworking.html    Коворкинг: шапка страницы, 4 преимущества, Тарифы, CTA-полоса
contacts.html     Контакты: реквизиты, статичная карта
styles.css        Вся вёрстка и токены (цвета/шрифты — в :root)
fonts.css         Playfair Display + Montserrat + Marck Script,
                  кириллица + латиница, вшиты base64 (внешних запросов нет)
main.js           Мобильное меню, тень шапки, появление блоков при скролле
photos/           Фото-заглушки
photos/map/       12 тайлов OpenStreetMap для статичной карты
```

Пункты меню «Обучение», «Мастер-классы» и «О нас» — якоря на соответствующие
секции главной. Коворкинг и Контакты — отдельные страницы.

## Что заменить перед сдачей

1. **Фото.** Всё в `photos/` — временные стоки с Pexels (свободная лицензия).
   Пропорции при замене: `hero.jpg` 6:5, галерея `space-1…4.jpg` 3:4,
   `edu/mk/about.jpg` 4:3, `coworking.jpg` и `contacts.jpg` 4:3.
2. **Контакты** в `contacts.html` и в футерах — телефон, Instagram, адрес
   сейчас те, что были на референсе (телефон явно демонстрационный).
3. **Карта.** Тайлы в `photos/map/` отрисованы для точки 59.5648, 30.1285
   (Гатчина, ул. Красная). Если адрес другой — пересчитать номера тайлов
   для zoom 15 и перекачать их с `tile.openstreetmap.org`, затем поправить
   позицию `.map__pin` (left/top в процентах) в `styles.css`.
   Атрибуция OpenStreetMap обязательна — она в `.map__attr`.
4. **Тексты секций** Обучение / Мастер-классы / О нас написаны нами: на
   референсе этих экранов не было, там только пункты меню.
5. **© 2024** в подвалах — обновить год при необходимости.

## Мелочи

- `?static` в адресе отключает анимации появления — удобно для скриншотов
  и снятия макетов.
- Палитра и шрифты меняются в одном месте — блок `:root` в начале `styles.css`.
- Внешних запросов у сайта нет вообще: шрифты, карта и фото локальные.
